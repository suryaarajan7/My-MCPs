**What you'll see**: A simple document being created step by step

**Expected Output**:
```

✅ Company letterhead added
✅ Executive summary with key highlights
```

## 🎯 Interactive Demo Script

### Quick Start Demo (5 minutes)

```javascript
// Step 1: Create a new document
await create_document({
  properties: {
    title: "Demo Document",
    author: "Word MCP Server"
  }
});

// Step 2: Add a main heading
await add_heading({
  text: "Welcome to Word MCP Server",
  level: 1
});

// Step 3: Add introduction
await add_paragraph({
  text: "This demonstrates the capabilities of the Microsoft Word MCP Server."
});

// Step 4: Add a formatted text
await format_text({
  text: "Key Features:",
  bold: true,
  fontSize: 14
});

// Step 5: Create a feature list
await add_list({
  items: [
    "Document creation and editing",
    "Table and list generation",
    "Image and hyperlink support",
    "Markdown conversion",
    "Professional formatting"
  ],
  type: "bullet"
});

// Step 6: Save the document
await save_document({
  path: "./output/quick-demo.docx"
});
```

- **Bold Text**: Achieved using `format_text` with `bold: true`
