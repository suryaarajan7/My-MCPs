## 🏗 Architecture Overview

### Core Components

#### 1. MCP Server (`src/index.ts`)
- **Purpose**: Main server implementing Model Context Protocol
- **Responsibilities**:
  - Handle MCP protocol communication
  - Manage document state
  - Route tool calls to appropriate functions
  - Error handling and validation
- **Dependencies**: `@modelcontextprotocol/sdk`

#### 2. Word Utilities (`src/word-utils.ts`)
- **Purpose**: Core Word document manipulation functions
- **Responsibilities**:
  - Create and manage Word documents
  - Add content (headings, paragraphs, tables, etc.)
  - Apply formatting and styles
  - Handle file I/O operations
- **Dependencies**: `docx`, `mammoth`, `jszip`, `axios`, `marked`

#### 3. Build System
- **TypeScript Compiler**: Compiles `.ts` files to `.js`
- **Build Output**: `build/` directory contains distributable files
- **NPM Scripts**: Automated build, test, and development commands

### Data Flow

```
MCP Client Request
    ↓
MCP Server (index.ts)
    ↓
Tool Router
    ↓
Word Utils (word-utils.ts)
    ↓
Document Generation
    ↓
Response to MCP Client
```

## 🎯 Available Tools

### Document Management (5 tools)
1. `create_document` - Initialize new Word documents
2. `save_document` - Export to .docx format
3. `load_document` - Open existing .docx files
4. `merge_documents` - Combine multiple documents
5. `set_document_properties` - Configure metadata

### Content Creation (6 tools)
6. `add_heading` - Insert numbered headings
7. `add_paragraph` - Add formatted paragraphs
8. `add_list` - Create bulleted/numbered lists
9. `add_table` - Generate tables with data
10. `insert_image` - Add images from files/URLs
11. `add_hyperlink` - Insert clickable links

### Advanced Features (4 tools)
12. `format_text` - Apply text styling
13. `add_table_of_contents` - Generate TOC
14. `parse_markdown` - Convert markdown to Word
15. `parse_json_structure` - Build from JSON data
